   One new Java feature I learned about from this project is lambda expressions and the method to recall it. I had researched this
topic before but this is my first time seeing it be utilized. I found them in the Main part of the code.
Statements such as players.forEach(p -> p.heal(1))(Line 41 Main). According to Oracle The p -> syntax creates a lambda expression, which allows a small piece of
code to be passed into another method. In this example, Java goes through each player in the list and calls the heal method on that player.
This is similar to using a normal for-each loop, but it can make simple operations shorter and easier to read. I also noticed a related
feature called a method reference in players.forEach(Player::addPotion)(line 179 Main). Again, According to Oracle, The :: syntax provides a shorter way to reference an
existing method when that is the only action that needs to happen. I think these features are useful because they can reduce
repetitive loop code when performing the same action on every object in a collection. Both methods in my opinion are used to make the code
presentable and readable. Yes, we can make a whole new function but I noticed that only the player might be able to use the "heal" function
in which the lambda expression would be able to get the job done cleaner. This is why I think these methods are useful. Its our job as
computer scientist to be efficient and make our code understandable.
